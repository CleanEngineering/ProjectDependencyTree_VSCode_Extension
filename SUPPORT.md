# Support

## Bug reports

Please open an issue in the GitHub repository:

https://github.com/CleanEngineering/ProjectDependencyTree_VSCode_Extension/issues

Include, when possible:

- VS Code version
- Extension version
- Operating system
- `.sln` or `.slnx`
- A concise description or sanitized example

Do not include credentials, private keys, secrets, or confidential source code.

## Feature requests

Feature requests are welcome through GitHub Issues. Please describe the problem or workflow you want to improve.
