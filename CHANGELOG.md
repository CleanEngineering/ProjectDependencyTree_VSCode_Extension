# Changelog

## 0.15.0

- Fixed Previous/Next navigation icon rendering.
- Preserved non-circular Previous/Next navigation and disabled states.
- Added balanced spacing to the project filter controls.

## 0.14.0

- Added Previous/Next navigation between repeated occurrences of the selected project.
- Navigation expands collapsed ancestors and centers the target occurrence.
- Navigation stops at the first and last occurrence.

## 0.13.0

- Improved project-list width and full-path visibility.
- Improved upstream highlighting for root projects.
- Added balanced tree spacing.

## 0.12.0

- Separated fixed headers from independently scrolling content areas.
- Added the supplied dependency-tree extension icon.

## 0.11.0

- Added bundled VS Code Codicons for tree actions and the dependency header.

## 0.10.0

- Refined the tree toolbar and project filter controls.
- Kept the selected project path in the relations panel and removed paths from relation entries.

## 0.9.0

- Added tree folding and expand/collapse controls.
- Added direct/indirect visual distinction in project relations.
- Updated publisher identifier to `CleanEngineering`.

## 0.8.0

- Added Marketplace-oriented metadata and documentation.

## 0.7.0

- Added Selected Project Relations with upstream/downstream direct and indirect counts.

## 0.6.0

- Improved `.slnx` project discovery.

## 0.5.0

- Added upstream dependency bolding for selected projects.

## 0.4.0
